# Security

This repository distributes connection metadata for the read-only guest Modulit MCP service. It contains no customer credentials, production source or private data.

Please report security issues privately to id@modulit.eu with the affected public URL, time and a minimal reproduction. Do not include real customer data, passwords or tokens in a public issue.

Guest access must preserve storefront, brand and geographic restrictions. A ChatGPT or other LLM login does not authenticate a Modulit customer. Private prices, exact stock, customer projects, reservations and payments are not part of this published integration.
